================================================================================
TEST 1 - SCALED FAIR BIDIRECTIONAL DAG / 1 KiB PAYLOAD COMPARISON
================================================================================
Official Sortledton transactional structures vs single-region SuperNova Fabric.
Each case uses the same logical N, K and fully populated H/V bounded DAG.
S-bidir uses two directed Sortledton edges/logical relation. Because this
Sortledton API has no Fabric-equivalent vertex payload row, 1 KiB/node is
encoded as 128 weighted payload edges in a disjoint namespace of the same Sortledton graph.
Four measured samples are taken per row with backend order alternated.
Bulk Sortledton read rows retain one snapshot/iterator per scan round.
Read/traversal rows use the bidirectional contract; replacement rows also
show S-native one-edge transactions as a non-equivalent lower bound.
Adapter lifecycle: one Sortledton graph + one transaction manager,
with disjoint topology/payload vertex namespaces.
